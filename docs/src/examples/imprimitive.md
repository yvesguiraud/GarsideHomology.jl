# Imprimitive braid groups

```@meta
CurrentModule = GarsideHomology
```

The groups G(m, m, n), for 3 ≤ n ≤ 8 and 3 ≤ m ≤ 30, whose dual braid monoid has at most 25 080 simples (as many as B*(E₈)) and which have at most 32 767 roots (which leaves out G(29, 29, 7)). In ℤ, the values agree with theorem 6.4 of Callegaro and Marin on H₀ = H₁ = ℤ and on H₂, and with the Poincaré polynomial they recall on the Betti numbers.
